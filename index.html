HTML 실행기

파일 앱의 html 을 골라 바로 실행합니다. 한 번 연 것은 아래 목록에 보관됩니다.

먼저 홈 화면에 추가하세요. Safari 공유 버튼 → 홈 화면에 추가 → 홈 화면의 아이콘으로 열어서 쓰면 전체 화면으로 열리고, 인터넷 없이도 실행됩니다. (Safari 와 홈 화면 앱은 보관함이 따로라서, 홈 화면 앱에서 파일을 열어 주세요.)

    사용법
    • html 파일 하나: 그대로 고르면 됩니다. 여러 개를 한꺼번에 고르면 각각 따로 목록에 들어갑니다.
    • 파일이 여러 개인 앱(html + js + css + 그림): 그 파일들을 한꺼번에 모두 고르세요. 하나의 앱으로 묶입니다.
    • 폴더째 들어 있는 앱: 파일 앱에서 폴더를 길게 눌러 압축 → 생긴 zip 파일을 고르세요. 폴더 구조가 그대로 유지됩니다.
    • 실행 중인 화면 가장자리의 둥근 버튼을 누르면 이 목록으로 돌아옵니다. 버튼은 끌어서 옮길 수 있습니다.
    • 같은 파일을 다시 열면 바꾸기(새 버전으로 교체)를 고를 수 있습니다.
    • 보관한 앱들은 같은 저장 공간을 함께 씁니다. 앱이 저장한 데이터(설정·자동 저장 등)는 목록에서 지워도 남아 있을 수 있습니다.
